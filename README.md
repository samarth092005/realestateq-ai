# 🏠 RealStateQ AI

AI-Powered Real Estate Analytics Platform built using Next.js, FastAPI, Firebase, Cloudinary, and XGBoost.

## 🚀 Live Demo

Frontend:
https://realestateq-ai.vercel.app/

Backend API:
https://realstateq-ai-backend.onrender.com

---

## 📌 Overview

RealStateQ AI is a full-stack real estate analytics platform that helps users discover, compare, and evaluate properties using artificial intelligence.

The platform combines modern web technologies with machine learning to provide intelligent property valuation and a seamless user experience for both buyers and brokers.

---

## ✨ Key Features

### 🔍 Property Discovery

* Browse available properties
* Search and filter listings
* View detailed property information

### 📊 Property Comparison

* Compare multiple properties side-by-side
* Analyze pricing and specifications
* Make informed decisions

### ❤️ Saved Properties

* Save favorite properties
* Manage personalized watchlists

### 👤 User Authentication

* Email/Password Authentication
* Google Authentication
* Secure Firebase-based user management

### 🏢 Broker Portal

* Add and manage property listings
* Broker profile management
* Verification status support

### ☁️ Cloud Image Management

* Property image uploads
* Cloudinary integration
* Optimized media delivery

### 🤖 AI Property Valuation

* Machine Learning powered property price prediction
* Real-time inference using FastAPI
* XGBoost regression model

## 🧠 Machine Learning Pipeline

→ Feature Engineering
→ Data Preprocessing
